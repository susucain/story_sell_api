# 系统虚拟人角色索引

系统虚拟人仅有以下 7 位。运行时角色目录是角色素材、默认服装和兼容服装的唯一权威来源；本文件只提供创作时的人设边界和题材建议。

| 别名 | 人设边界 | 适用内容 |
|---|---|---|
| 小叶 | 软萌亲和的年轻女性插画师 | 文创、设计、年轻化内容 |
| 程曦 | 干练亲和的年轻女性互联网实习生 | 科技、职场、商务 |
| 青黛 | 温婉清新的女性国风插画师，现代国风气质 | 国风、文旅、传统文化 |
| 小岚 | 自然利落的女性新媒体运营，适合镜头前口播 | 探店、餐饮、本地生活 |
| 瑶琴 | 端庄典雅的女性先秦名伶 | 先秦、历史、古典文化 |
| 云游 | 清冷自在的女性玄幻散修 | 仙侠、玄幻、奇幻 |
| 凌霜 | 英气果断的女性武林侠客 | 武侠、江湖、古风剧情 |

## 使用规则

1. 用户指定上述别名时，使用对应系统虚拟人，并保持人设边界稳定。
2. 未指定人物但脚本需要人物时，可按商品画像和题材自动选择其中一位。
3. 用户要求已下线的旧文本角色时，必须要求其从上述 7 位中选择，不得自动映射。
4. 角色服装必须由运行时目录确定：未指定服装时使用默认服装；指定服装时只使用兼容组合；自定义服装不得与现代或古风视觉族群冲突。
5. 分镜中可补充角色动作、表情和场景，但不得改变角色职业、时代或题材边界。
