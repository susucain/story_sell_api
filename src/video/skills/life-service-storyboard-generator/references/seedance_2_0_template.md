# Seedance 2.0 提示词生成规范

本文件定义了生成 Seedance 2.0 视频提示词的严格标准。所有生成的 `seedance_prompts.md` 文件必须完全符合以下结构。

## ⚠️ 绝对红线 (CRITICAL)
**全中文要求**：Seedance 2.0 模型完全支持中文输入。生成的所有内容（包括字段名、标签、描述内容）必须严格使用**简体中文**。**严禁出现任何英文单词**（除非是不可翻译的专有名词，如 "App Store"）。

## 调用 generate_script 前强制校验

以下任一项不满足时，必须先在本次推理中改写提示词；不得依赖 `generate_script` 返回校验错误后再修正。

1. **素材引用**：禁止出现 `asset-...`、`[asset-...]`、素材数据库编号或“参考图1/参考视频1”。只能使用 `@图片N`、`@视频N`、`@音频N`，人物素材应写为 `<主体N>@图片N中的人物`。
   - 错误：`让 [asset-123] 中的人跑向镜头`、`@图片1跑向镜头`
   - 正确：`让 <主体1>@图片1中的人物跑向镜头`
2. **视频编辑引用**：局部编辑或延长任务只能写“严格编辑 @视频N”或“向前延长 @视频N / 向后延长 @视频N”，禁止写“参考 @视频N”。
   - 错误：`严格编辑 @视频1，参考 @视频1，将背景替换为海边`
   - 正确：`严格编辑 @视频1，将背景替换为海边`
3. **一镜一运镜**：每个“镜头N”只能指定一种运镜方式，例如推、拉、摇、移、跟拍、固定机位之一；需要切换运镜时必须拆为下一个镜头。
   - 错误：`镜头1：先推镜头，随后拉镜头`
   - 正确：`镜头1：推镜头，突出菜品细节`
4. **多镜头时序**：两个及以上镜头只使用“镜头1、镜头2”的顺序表达，禁止出现任何绝对秒数或时间段，例如 `0-3秒`、`3s`、`3-6秒`。
5. **提交前复核**：逐项检查以上规则，再调用 `generate_script` 保存完整 `storyboard_markdown`、`seedance_prompt` 和 `meta`。

## 核心原则
1.  **结构严格**：必须保留所有 `**[字段名]**` 标记。
2.  **中文输出**：所有描述性内容必须使用中文。
3.  **人物一致**：必须在文件开头定义 `人物设定`，并在每个涉及人物的镜头中重复关键特征。
4.  **素材还原**：如果用户提供了图片/视频素材，必须在提示词中精准还原其视觉特征（如装修风格、菜品摆盘）。
5.  **细节丰富**：避免抽象描述，使用具象的视觉语言（如颜色、材质、光影）。

### [镜头语言]
请从以下列表中选择最合适的运镜词汇，确保专业性。

基础运镜:
- **推 (Dolly In / Push In)**: 镜头向前推进，强调主体或细节。
- **拉 (Dolly Out / Pull Out)**: 镜头向后拉远，展示全景或揭示环境。
- **摇 (Pan)**: 镜头左右摇动，展示宽阔场景或跟随主体移动。
- **移 (Truck)**: 镜头横向移动，展示环境层次或平行跟随。
- **升/降 (Pedestal / Crane)**: 镜头垂直上下移动，改变视角高度。
- **跟 (Tracking)**: 镜头跟随移动的主体（前跟、后跟、侧跟）。

高级/组合运镜:
- **环绕 (Orbit)**: 镜头围绕主体360度旋转，多角度展示。
- **甩镜 (Whip Pan)**: 极快速的摇镜，常用于转场。
- **希区柯克变焦 (Dolly Zoom)**: 推轨同时变焦拉，产生眩晕感。
- **手持运镜 (Handheld)**: 模拟手持拍摄，增加真实感和呼吸感。
- **第一人称视角 (POV)**: 模拟人眼视角，增强代入感。
- **极特写 (Extreme Close-up)**: 极近距离拍摄，展示微观细节（如食物纹理）。

景别与角度:
- **景别**: 远景 (Long Shot)、全景 (Full Shot)、中景 (Medium Shot)、近景 (Close-up)、特写 (Close-up)。
- **角度**: 俯拍 (High Angle)、仰拍 (Low Angle)、平视 (Eye Level)、鸟瞰 (Top Down)。
