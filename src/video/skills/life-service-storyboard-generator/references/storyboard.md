# 分镜创作

## 前置分析

在一次推理中完成脚本重写模式的分析、设计和分镜生成；完整视频编辑不重建设计、镜头拆分或完整分镜，只分析输入视频和用户指定的修改范围。

可用用户画像时用它了解偏好；不存在时使用默认设置。严格遵守内容安全规范。

分析素材时：

- 图片：观察环境风格（灯光、装修）、菜品细节（颜色、质感、摆盘）和人物特征，并把这些视觉信息直接用于画面描述。
- 门头检测：有门头图时记录招牌颜色、文字和装修风格，可用于开场；没有门头图时标记为无门头素材，后续不得虚构门头或外观镜头，只能从店内环境或菜品开始。
- 文本：提取核心卖点（价格、特色、位置）。

按关键词识别类型：团购、套餐、优惠、9.9、折扣属于 A；探店、打卡、体验、评测属于 B；低价、便宜、划算、秒杀、代金券属于 C；广告、宣传片、品牌片、产品广告、商业广告、奢侈品、二手店、珠宝、腕表、高端属于 D；对话、对比、别人家、价格对比、回收对话、顾客视角属于 E。

用户未提供时询问主题（核心卖点）、受众、时长（15/30/60 秒）和版式（含运镜的专业版或极简版）。

## 结构与检查

按视频类型使用下列叙事结构：

- 团购套餐：福利钩子（菜品蒸汽、人物动作、色彩对比或构图，不用手牌或标题图层）-> 套餐全览 -> 招牌特写 -> 环境配套 -> 行动号召。
- 达人探店：探店引入 -> 进店初印象 -> 点单/体验 -> 核心高光 -> 推荐/CTA。
- 广告场景：产品特写引入 -> 人物与环境揭示 -> 互动过程展示 -> 价值/价格展示 -> 品牌/收尾。
- 顾客对话对比：顾客提出问题/对比 -> 商家报价（价格优势）-> 顾客惊讶/追问 -> 商家再次报价加解释 -> 专业背书加 CTA。

单镜头建议 3-5 秒，最长不超过 15 秒；短镜头制造兴奋感，长镜头渲染氛围。输出前检查：

- 前 3 秒出现核心卖点。
- 本地生活有食欲感，广告场景有高级质感。
- 无过长镜头。
- 结尾有明确 CTA：本地生活是购买引导，广告场景是品牌认知或咨询引导。
- 广告场景使用正确节奏和运镜。
- 无门头素材时没有虚构门头或外观镜头。
- 探店旁白像朋友分享，不使用“必须冲”“绝绝子”等过度营销词。
- 用户明确提出“检查劣质营销”“合规检查”或“避免违规”时，逐项执行劣质营销九大红线检查。

## 分镜内容

在内存中准备 Markdown 分镜，再通过 `generate_script` 保存，不在对话中输出分镜。画面描述必须与素材分析的视觉信息一致。人物有惊讶、大笑等夸张表情时，加入“眼神自然”“避免僵硬”等约束。

无门头素材时禁止出现“站在店门口”“站在招牌下”“手指门店招牌”“店铺外观”“门头特写”“外观全景”或任何虚构门头/外观；可改为店内环境、菜品特写或店内装修开场。

专业版模板：

```markdown
### 镜头 [N]：[标题] ([开始时间] - [结束时间])
- **画面描述**：[视觉描述]
- **画面元素**：[文字/图形]
- **运镜**：[运镜方式]
- **音效**：[音效]
- **旁白**：[旁白内容]
```

极简版模板：

```markdown
### 镜头 [N] ([时间])
- **画面**：[描述]
- **旁白**：[旁白内容]
```

每个分镜导出前都执行脚本、语音和无文字画面一致性检查：口播逐字逐句匹配旁白，禁止即兴发挥；画面无字幕、标题、标语、按钮或其他可读文字；脚本、语音和画面不得出现具体价格数字，只使用“超值”“低价”等模糊描述。

## 营销与画面质量

所有内容必须规避以下九类劣质营销：虚构场景或无关素材造成虚假感受；emoji、谐音字、字母缩写等不规范用字；无铺垫广告或过度营销词；美女博眼球、影视明星或赌博新闻等不相关素材；卖惨或经营困难描述；营销素材时长过长；不明确交易信息；冒充客户口吻；缺乏真实试吃细节和感官描述。

价格脱敏；CTA 必须包含“限时活动，先囤券再消费，不用随时退”。探店明确达人身份并使用分享语气。仅在用户明确要求时生成前逐项检查九大红线；最终发现红线必须立即重写。

广告场景以固定机位为主，可轻微手持抖动增加真实感；产品特写优先，强调细节质感；缓慢运镜，避免快速切换；人物保持专业形象，避免夸张表情。价格和品牌信息由后期添加，模型画面不得生成特效字幕、Logo 或其他文字。

建议使用具体 BGM 风格（如欢快 Lo-Fi、快节奏 Trap），使用微距镜头展示食物纹理，并使用具体行动号召（如点击下方链接、来指定地址打卡）。
