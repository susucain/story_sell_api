# 广告场景类型配置 (Ad Commercial Config)

> 📌 **定位**：高端商业宣传广告，专注于奢侈品二手店、珠宝腕表、高端消费品等场景
> 
> 💡 **核心特点**：与本地生活团购/探店隔离，强调品牌质感、产品细节、价值传递

---

## 🎯 类型定义

**类型名称**：广告场景 (Ad Commercial)

**触发关键词**：广告、宣传片、品牌片、产品广告、商业广告、奢侈品、二手店、珠宝、腕表、高端

**适用场景**：
- 奢侈品二手店宣传
- 珠宝/腕表产品展示
- 高端消费品广告
- 品牌宣传片
- 产品开箱展示
- 高端服务介绍

---

## 📐 技术参数

### 时长配置
- **标准时长**：30-45 秒
- **镜头数量**：20-35 个镜头
- **单镜头时长**：1.0-2.0 秒（以 1.3s 为基准）
- **画幅比例**：9:16（竖屏）或 16:9（横屏）

### 节奏特征
- **整体节奏**：中慢速，强调质感
- **运镜方式**：固定机位为主，轻微手持抖动增加真实感
- **景别分布**：
  - 特写（Close-up）：40%（产品细节）
  - 中景（Medium Shot）：50%（人物互动）
  - 全景（Full Shot）：10%（环境展示）

### 视觉风格
- **色调**：暖色调或中性色，低饱和度
- **光线**：柔光、侧光，避免强烈对比
- **质感**：高级感、精致、专业
- **特效**：仅使用不含文字的光影和材质特效；价格与品牌信息由后期添加

---

## 🎬 典型叙事结构

### 结构模板：奢侈品展示广告

```
1. 产品特写引入 (3-5 镜头，约 4-6 秒)
   - 手持产品特写
   - 多角度展示细节
   - 轻微运镜或固定机位

2. 人物与环境揭示 (2-3 镜头，约 3-4 秒)
   - 缓慢拉远或推进
   - 揭示人物和环境
   - 建立场景关系

3. 互动过程展示 (8-12 镜头，约 10-15 秒)
   - 完整展示人物与产品的互动
   - 交接、查看、试用等动作
   - 固定机位，强调真实感

4. 价值/价格展示 (3-5 镜头，约 4-6 秒)
   - 用产品质感、人物互动和光影表现价值，不生成价格或文字
   - 人物展示产品给镜头
   - 金色/闪光特效（如适用）

5. 品牌/收尾 (2-3 镜头，约 3-4 秒)
   - 人物正视镜头
   - 品牌信息或行动号召
   - 定格收尾
```

## 📝 画面提示词规范

### 特写镜头（产品细节）
```
手拿 [产品名称]，背景露出 [人物特征]，[环境描述]
固定机位，轻微手持抖动
```

### 中景镜头（人物互动）
```
[人物描述] 伸手准备 [动作]，[背景元素] 清晰
固定机位
```

### 运镜镜头（揭示环境）
```
镜头 [拉远/推进]，[人物/产品] 完整入镜，背景出现 [环境元素]
缓慢 [拉远/推进]
```

### 特效镜头（价值展示）
```
[产品] 移到画面 [位置]，无文字的光影特效强化材质
固定机位，[颜色] 闪光特效
```

## 🎭 人物与场景设定

### 人物特征
- **着装**：职业装、正装、品牌制服
- **神态**：专业、自信、从容
- **动作**：优雅、缓慢、有仪式感
- **互动**：真实自然，避免夸张表情

### 场景特征
- **环境**：高端店铺、展厅、精品店
- **背景**：奢侈品陈列、品牌墙、精致装修
- **光线**：柔和、温暖、有层次
- **道具**：产品礼盒、展示台、品牌包装

---

## ⚠️ 制作红线

### 必须遵守
1. **产品真实性**：严格基于真实产品描述，不得虚构
2. **价格准确性**：如有价格展示，必须与用户提供的一致
3. **品牌合规**：不得出现未授权的品牌 LOGO 或商标
4. **人物专业度**：避免夸张表情和动作，保持专业形象

### 禁止内容
- ❌ 夸张的促销语言（"跳楼价"、"亏本甩卖"）
- ❌ 低俗或擦边球内容
- ❌ 虚假宣传或误导性信息
- ❌ 侵犯知识产权的内容

## 🎨 与本地生活的差异

| 维度 | 本地生活（团购/探店） | 广告场景（奢侈品） |
|------|---------------------|-------------------|
| **目标** | 促进即时消费 | 品牌价值传递 |
| **节奏** | 快节奏（2-4 秒/镜头） | 中慢速（1-2 秒/镜头） |
| **运镜** | 快速推拉、甩镜 | 固定机位、缓慢运镜 |
| **景别** | 特写为主（食物） | 特写 + 中景（产品 + 人物） |
| **人物** | 达人/主播（亲和力） | 专业人士（信任感） |
| **价格** | 模糊处理（低价/超值） | 精确展示（31000 元） |
| **特效** | 少或无 | 适度使用（价格特效等） |
| **BGM** | 欢快、快节奏 | 优雅、舒缓、高级感 |
| **转化目标** | 点击购买 | 品牌认知/到店咨询 |

## 📊 质量检查清单

### 结构检查
- [ ] 是否包含产品特写引入？
- [ ] 是否有人物与环境揭示？
- [ ] 是否完整展示互动过程？
- [ ] 是否有价值/价格展示（如适用）？
- [ ] 是否有品牌收尾？

### 画面检查
- [ ] 特写镜头是否清晰展示产品细节？
- [ ] 中景镜头是否展现真实人物互动？
- [ ] 运镜是否平稳、有质感？
- [ ] 背景环境是否符合高端定位？
- [ ] 特效使用是否适度？

### 人物检查
- [ ] 人物着装是否专业？
- [ ] 神态是否从容自信？
- [ ] 动作是否优雅自然？
- [ ] 是否避免夸张表情？

### 合规检查
- [ ] 产品信息是否真实准确？
- [ ] 价格展示是否有依据？
- [ ] 是否无侵权内容？
- [ ] 是否无虚假宣传？

## 🔗 使用示例

### 示例 1：奢侈品二手店广告
```
使用 life-service-storyboard-generator 生成一个广告场景视频，用于奢侈品二手店宣传。
店铺名称：XX 奢侈品集合店
主打产品：梵克雅宝四叶草手链、爱马仕 Birkin 包
目标受众：25-40 岁女性，追求品质生活
时长：30 秒左右
参考风格：高端、专业、有质感
```

### 示例 2：珠宝腕表广告
```
生成一个珠宝腕表的产品广告。
产品：卡地亚蓝气球腕表
特色：18K 金、自动机械机芯
价格：¥68,000
场景：高端腕表专柜
要求：强调产品细节和专业感
```

### 示例 3：高端服务宣传片
```
制作一个高端奢侈品养护服务的宣传片。
服务内容：奢侈品包袋清洁、修复、保养
服务流程：接收→检测→清洁→修复→质检→交付
目标客户：奢侈品拥有者
时长：45 秒
```
